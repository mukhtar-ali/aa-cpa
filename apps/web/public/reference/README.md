# Reference page placeholders

Neutral placeholder images for the design-system reference page (`/<lang>/reference/home`). They are generated flat-colour SVGs created for this
repository: no photographs, no third-party artwork and no client logos, so there is nothing to license. Real photography replaces them in
feature 003 (licensed stock or client-supplied, with sources recorded). Figma images with watermarks (for example envato previews) must never
be added here.
